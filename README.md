# CyberArk PAM Lifecycle Lab

## Overview
This project demonstrates hands-on experience with CyberArk Privileged Access Management (PAM), focusing on managing privileged accounts and their lifecycle.

## What I Did
- Managed privileged accounts in CyberArk
- Organized accounts into Safes
- Performed account lifecycle operations:
  - Onboarding (adding accounts)
  - Verification
  - Reconciliation
  - Deletion
- Observed account states and security controls

## Key Concepts Demonstrated
- Privileged Access Management (PAM)
- Safe management
- Account lifecycle (Create → Manage → Delete)
- Security and access control
